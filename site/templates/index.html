// Bind definitions to variables.
let (mut stages, [decode, resize]) =
    Stages::define(pulse, [
        PhaseSpec::new("decode", 4, Total::Unknown),
        PhaseSpec::new("resize", 3, Total::Unknown),
    ]);

// Call your functions as usual.
let decode = stages.begin(decode);
let pixels = decode_image(input, &decode)
    .finish_phase(decode)?;

let resize = stages.begin(resize);
let pixels = resize_image(pixels, &resize)
    .finish_phase(resize)?;

stages.complete(Ok(pixels))

Keep your return types
Return your own Result<T, E>. Implement AsStopReason on your error to distinguish cancellation from failure.
02
Compose ordinary calls
Stages can take different inputs and return different types. Forked handles use the same result handoff; your runtime schedules the work.
03
Let the caller choose
Pass NoPulse, a stop token adapter, or a tracker. Your library reports work. Its caller owns the display and final completion.
